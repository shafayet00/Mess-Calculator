# Mess Calculator 🏠🍽️

**Mess Calculator is a web and Android-based mess management application designed to simplify shared living expenses, meal tracking, member management, and monthly accounting for friends living together in a mess.**

It helps a mess manager keep track of daily meals, deposits, expenses, other costs, member balances, and final settlements in one place.

## ✨ Features

- 👥 **Mess & Member Management** — Create a mess, invite members with a unique invite code, and manage member roles.
- 🍚 **Meal Tracking** — Record daily meals for individual members and calculate the total meal cost automatically.
- 💰 **Mess Fund Management** — Add deposits, withdraw funds, and transfer deposits between members.
- 💳 **Expense Management** — Track food expenses and other shared expenses separately.
- 📊 **Monthly Accounting** — View meal totals, food cost, other cost, deposits, balances, and member-wise settlements.
- 🔐 **Manager & Member Roles** — Managers can manage data; members can view mess information without editing protected records.
- ☁️ **Cloud Sync** — Data is synchronized through Supabase so mess members can stay updated.
- 📄 **PDF Report** — Generate a clean monthly report with summary and member cost details.
- 📱 **Responsive UI** — Designed for desktop and mobile screens.
- 🌙 **Theme Support** — Clean light/dark interface for comfortable use.
- 🔒 **Authentication** — Account-based login and secure workspace access.

## 🧮 What Can Be Managed?

### Meals
Track how many meals each member takes every day and use the total meal count to calculate the meal rate.

### Mess Fund
Manage member deposits and fund transactions so the available mess balance stays clear.

### Expenses
Record:
- Food expenses
- Other mess expenses
- Shared expenses

### Member Settlement
The system calculates each member's:
- Total Deposit
- Food Cost
- Other Cost
- Total Cost
- Final Settlement

## 🎯 Project Goal

The goal of **Mess Calculator** is to replace manual notebooks, calculators, and spreadsheets with a simple digital system for managing a shared mess.

Instead of calculating everything manually at the end of the month, members can keep their meals, deposits, expenses, and settlements organized throughout the month.
